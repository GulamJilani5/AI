# ⏺️ Pretraining

- The phase where a model learns general language understanding from massive unlabeled text.
- A model (like **BERT**, **GPT**, **Llama**) is trained on billions of sentences from the internet, books, etc.
- No human labels — it's self-supervised.
- **Goal:** Learn patterns, grammar, facts, reasoning in language.

### ➡️ Common Pretraining Tasks:

- Masked Language Modeling (MLM)
- Next Token Prediction
- Contrastive Learning

### ➡️ After Pretraining:

- The model has rich embeddings and general knowledge.
- It can generate text, answer questions — but not perfectly tuned for specific tasks.

- **Analogy:** Pretraining = Sending a student to school for 12 years to learn reading, math, history.
  They’re smart, but not yet a doctor or lawyer.
